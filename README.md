# AI-Based Image Recognition System

An AI-powered image classification system that uses **Deep Learning and CNN (Convolutional Neural Networks)** to identify and classify images into predefined categories.

## Features
- Image Upload and Classification
- Image Preprocessing (Resizing & Normalization)
- Data Augmentation
- CNN Model Training
- Model Accuracy Comparison
- Prediction with Confidence Score

## Technologies Used
- Python
- TensorFlow / Keras
- CNN
- NumPy
- Matplotlib
- Streamlit

## Objective
To develop an intelligent image recognition system that accurately classifies uploaded images and displays prediction results with confidence scores.
